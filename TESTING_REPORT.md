# CivicLens — Evidence-Based Quality Assurance & Testing Report

**Environment Tested**: Node.js + Express (`tsx server.ts`) on `http://localhost:3000`, SQLite (`better-sqlite3` WAL), Google Gemini API (`@google/genai` server-side).  
**Integrity Policy**: Only checks actually executed against the running application or build toolchain are marked **Pass**. Items requiring hands-on browser viewport verification are explicitly marked **Not tested (manual check required)**.
